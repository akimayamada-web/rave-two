# Rave Two — быстрый прототип

Минимальный веб-прототип совместного просмотра для двух участников.

## Запуск на компьютере

1. Установите Node.js 18 или новее.
2. Распакуйте архив и откройте терминал в папке проекта.
3. Выполните:

```bash
npm install
npm start
```

4. Откройте http://localhost:3000

## Как проверить вдвоём

- Для проверки на одном компьютере откройте сайт в двух разных браузерах/окнах.
- Нажмите «Создать комнату» в первом окне.
- Во втором введите тот же код и нажмите «Войти».
- Вставьте ссылку на YouTube или прямую ссылку на MP4/WebM и нажмите «Загрузить видео».
- Play / pause / перемотка синхронизируются между участниками.

## Как дать другу подключиться через интернет

Нужно разместить папку проекта на Node.js-хостинге, который поддерживает WebSocket (например, Render или Railway), и отправить другу HTTPS-ссылку на сайт. Локальный `localhost` доступен только на вашем устройстве.

## Ограничения прототипа

- Поддерживаются прямые ссылки на видеофайлы MP4/WebM, доступные обоим участникам.
- YouTube поддерживается через официальный IFrame Player API, если автор разрешил встраивание. Netflix и другие DRM-сервисы не поддерживаются.
- Комнаты хранятся в памяти сервера и исчезают после перезапуска.
- Это MVP без аккаунтов, чата и постоянного хранения.
